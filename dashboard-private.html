Google 로그인은 바로 가능해요. 최초 MASTER 파일 선택 시 Picker 설정이 필요할 수 있어요.

비밀번호는 Google에만 입력합니다. MASTER와 인증 토큰은 공개 저장소에 올리지 않습니다.

🔒 개인 데이터 보호: 이 GitHub Pages는 공개 웹페이지지만 MASTER 파일은 공개하지 않습니다. Google 인증과 사용자가 선택한 Drive 파일 권한이 있어야 원본을 읽을 수 있습니다. 이 페이지는 파일 읽기(GET)만 수행합니다. Google이 제공하는 drive.file 범위에는 수정 권한도 포함될 수 있어 동의 내용을 확인해 주세요. 이 기기는 연결 파일의 ID만 기억할 수 있습니다. 실시간 시세는 아직 미연결입니다.
